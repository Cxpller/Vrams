# VRAMS Project Analysis Skill


## Purpose

帮助分析 VRAMS 项目的整体结构。


## When to use

当用户要求：

- 分析项目
- 理解代码结构
- 评估架构
- 新功能设计


## Steps


1. Read project structure

2. Identify:

- frontend modules
- backend modules
- database layer
- communication layer


3. Check:

- code organization
- dependency management
- architecture consistency


4. Output:

- current architecture
- problems
- suggestions
